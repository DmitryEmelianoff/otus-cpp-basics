Данный репозиторий создан в рамках обучения на курсе по C++ в образовательном центре OTUS.

Основная цель — закрепление теоретических знаний на практике путем выполнения серии домашних заданий, предусмотренных учебной программой. Репозиторий служит портфолио выполненных работ и демонстрирует прогресс в изучении языка C++ и смежных технологий.

В этом репозитории будут размещены решения следующих типов задач:
* домашние задания по основам C++;
* итоговые проекты по курсу.
